# 张叡词曲52首

🌐 公开网站（谁都能打开）：https://rzcrane999-dotcom.github.io/zhangrui-52-songs/

张叡作词、作曲的 52 首歌曲（由雪非编辑、发表于其美篇账号）的网络汇总页，
用于发布到 GitHub Pages，供大家在线浏览。

## 网站内容

- `index.html` —— 52 首歌曲目录（按序号），点击进入单曲页
- `songs/NN.html` —— 单曲页：诗词全文、演唱版歌词（如与诗文有异则并列展示）、
  MP3 演唱音频（在线播放＋下载）、五线谱 PDF（在线预览＋下载）、美篇原文链接
- `audio/NN.mp3` —— 演唱音频，64kbps 单声道（体积压缩版）
- `scores/NN.pdf` —— 五线谱 PDF

## 署名

每首：**词：张叡　曲：张叡**（雪非为美篇编辑）。

## 说明

五线谱为根据音频自动分析和对齐的转写稿，仅供学习参考。
